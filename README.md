# 汎用ダイヤグラム

路線を固定せず、任意の駅・列車を登録できる鉄道ダイヤグラム作成サイトの初期版です。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：デザイン・レスポンシブ表示
- `app.js`：駅・番線・列車・時刻・ダイヤ描画・JSON入出力

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成する
2. このフォルダ内の3ファイルとREADMEをリポジトリ直下にアップロードする
3. Settings → Pages を開く
4. Build and deployment の Source を「Deploy from a branch」にする
5. Branch を `main`、フォルダを `/(root)` にして Save
6. 公開URLが表示されるまで待つ

## 現在実装している機能

- 任意の路線・ダイヤ名
- 駅の追加・削除、起点からの距離
- 駅ごとの番線名設定
- 列車番号・種別・行先・表示色
- 各駅の時刻入力
- 列車ごとの使用番線指定
- 入力した時刻からダイヤグラムを自動描画
- JSON形式で保存・読み込み

## 今後の実装予定

- OuDia / OuDiaSecond（.oud / .oud2）の読み込み・書き出し
- 車両編成・運用番号・入出庫・運用変更管理
- 停車駅・通過駅の詳細属性
- ダイヤの拡大縮小、時間軸・距離軸設定
- 印刷・画像出力

## 注意

この初期版のデータ保存先は、利用者がダウンロードするJSONファイルです。ブラウザを閉じても自動保存される仕組みや、複数端末間の同期はまだありません。
