# 汎用ダイヤグラム ver.05
## フォント・表示デザイン更新
- UIは日本語のシステムゴシック体を優先
- ダイヤの数字は等幅フォント＋tabular numerals
- SVG内の駅名・列車番号も専用フォント設定
- タブ・カード・入力欄を整理し、モバイル表示に対応

## 使用方法
GitHub Pagesなどで公開する場合、index.html / style.css / app.js を同じ階層に配置。
データはブラウザ内(localStorage)に保存。JSONの書き出し・読み込みにも対応。

## 現状
駅、列車、車両、運用の簡易登録とダイヤ描画を実装。駅別到着/発車時刻を入力できます。
このバージョンは基本的な試作で、.oud/.oud2対応、列車運用の自動連結、番線占有検査、詳細な運転曲線等は未実装です。
