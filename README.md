# 汎用ダイヤグラム Ver.0.2

## ファイル
- `index.html`：画面構成
- `style.css`：デザイン
- `app.js`：駅・番線・列車・秒単位時刻・運用・描画・保存処理

## Ver.0.2 の追加
- HH:MM:SS形式の時刻入力（HH:MMも可）
- 列車ごとの運用番号割当
- 運用番号・車両名の登録と一覧表示
- 駅ごとの番線名設定、列車ごとの使用番線指定
- ブラウザの localStorage への自動保存
- JSONの保存・読み込み（運用データも含む）

## GitHub Pagesへの反映
既存リポジトリの `index.html` `style.css` `app.js` `README.md` を、この版の同名ファイルで置き換えてコミットしてください。GitHub Pagesの設定は通常そのままで構いません。

## 現時点の制限
- 運用列車の表示は登録した列車の割当一覧です。列車間の接続可能性や折返し時間の自動判定は未実装です。
- 番線は列車ごとの指定を保存しますが、番線在線の時間帯表示・競合検知は未実装です。
- .oud / .oud2 のパーサー・書き出しは未実装です。
- 入出庫・車両基地在線バー、箱ダイヤ、印刷出力は今後の実装対象です。
- 自動保存は同じブラウザ内のみです。定期的にJSON保存してください。
